Button sounds for Dup Me
========================

animal/  real animal sounds   (pig, dog, crow, chicken, cow).mp3
thai/    animal names in Thai  หมู หมา กา ไก่ วัว  (pig, dog, crow, chicken, cow).mp3

To use your own recordings (e.g. record yourself saying หมู หมา กา ไก่ like the TikTok trend),
just replace the file with the same name. Short clips (under ~1.5 s) work best.
If a file is missing, the game falls back to a simple beep.

Credits
-------
Animal sounds: trimmed from the ESC-50 dataset (K. J. Piczak, "ESC: Dataset for Environmental
Sound Classification", 2015), clips originally from freesound.org, licensed CC BY-NC 3.0.
  pig     -> ESC-50 3-253084-A-2  (freesound #253084)
  dog     -> ESC-50 2-118072-A-0  (freesound #118072)
  crow    -> ESC-50 1-96950-A-9   (freesound #96950)
  chicken -> ESC-50 2-95035-A-1   (freesound #95035, rooster)
  cow     -> ESC-50 1-69422-A-3   (freesound #69422)
Non-commercial use only (fine for a class project).

Thai words: generated with espeak-ng (GPL-3.0 speech engine; the output audio is free to use).
